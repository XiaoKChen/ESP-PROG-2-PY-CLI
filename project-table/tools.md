pyOCD configuration and flashing-prerequisite notes.

- **Responsibility:** Make bare `pyocd` commands work without repeating flags, and document what's needed to flash.
- **Key files:** `pyocd.yaml`, `README.md`.
- **Relationships:** Optional helper for manual pyOCD use; the TUI/CLI set the same options in code and don't require it.

- **`pyocd.yaml`** — pyOCD config setting `target_override: r7fa4m1ab` and `frequency: 1000000`, so `pyocd flash hex/dfu_minima.hex` works from the project root without `-t`.
- **`README.md`** — Lists the flashing requirements (pyOCD + the `r7fa4m1ab` device pack, the ESP-Prog-2 CMSIS-DAP probe wired to the target's SWD pins) and explains why OpenOCD is not used (the installed build lacks the `renesas_ra` flash driver).
