- **Responsibility:** Holds the drop-in pyOCD configuration and setup/rationale documentation for flashing the RA4M1 (UNO R4 Minima) target board via the ESP-Prog-2's CMSIS-DAP probe.
- **Key files:** `pyocd.yaml`, `README.md`
- **Relationships:** Read by the `pyocd` CLI (via `uv run pyocd`) when invoked from the project root, letting commands like `pyocd list` / `pyocd flash hex/dfu_minima.hex` / `pyocd reset` run without a `-t` flag; the project's Python TUI/CLI applies the same `target_override`/`frequency` options in code rather than depending on this file; README documents that OpenOCD is unusable for flashing (missing `renesas_ra` flash driver in the installed xPack build) and is only for connection tests.

- **pyocd.yaml** — pyOCD config pinning `target_override: r7fa4m1ab` and `frequency: 1000000` (1 MHz SWD clock), so bare `pyocd` commands run from the project root target the RA4M1 without repeating `-t`.
- **README.md** — Explains flashing requirements (pyOCD as a project dependency, the `r7fa4m1ab` CMSIS device pack, the ESP-Prog-2 probe as a CMSIS-DAP device with VID `0x303A`/PID `0x1002`), documents the purpose of `pyocd.yaml`, and explains why OpenOCD is not used for flashing (missing `renesas_ra` flash driver in the installed xPack OpenOCD 0.12 build; only Arduino's OpenOCD fork ships it).
