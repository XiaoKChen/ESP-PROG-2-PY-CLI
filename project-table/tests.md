**tests/** — Hermetic pytest suite: the encoders, flashing plans, CLI decisions, port auto-detect rules, the saved-state file and the headless Textual dashboard, all without a probe, board or serial port.

- **Responsibility:** Covers byte-exact encoders/decoders, the SOLO esptool command plan, CLI write decisions, probe-port classification, PSoC 6 segment filtering, the saved-state file, and the TUI via `App.run_test()`. Run with `uv run pytest`.
- **Key files:** `test_app.py`, `test_flasher.py`, `test_dfu_config.py`, `test_board_profile.py`, `test_state.py`
- **Relationships:** Imports from `src/esp_prog2_flasher/` (`flasher`, `cli`, `app`, `dfu_config`, `board_profile`, `tui.*`), plus pytest, textual (`Pilot`) and intelhex. Exposes nothing. Every file opens with a docstring carrying Covers / Not covered / See also. No `conftest.py`; `tests/.gitkeep` is a placeholder.
- **Hermeticity:**
  - `test_app.py` autouse fixture `hermetic_state` redirects `tui.state.default_state_path` into `tmp_path`, so no test touches the real config dir.
  - Autouse `no_hardware` fakes `flasher.detect` / `detect_psoc6` (NO_PROBE), `find_probe_serial` (None) and `list_serial_ports` (a COM3 bridge plus a COM9 `303A:1001` port); flash/provision calls are swapped for recorders.
  - Pilot coroutines run via `asyncio.run` (no async plugin). `test_flasher.py` injects a `FakeEsptool` flash emulator and a fake `gh`; `test_state.py` works only under `tmp_path`.
