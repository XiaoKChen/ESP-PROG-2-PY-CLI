  - `test_app.py` autouse fixture `hermetic_state` redirects `tui.state.default_state_path` into `tmp_path`, so no test touches the real config dir.
  - Autouse `no_hardware` fakes `flasher.detect` / `detect_psoc6` (NO_PROBE), `find_probe_serial` (None) and `list_serial_ports` (a COM3 bridge plus a COM9 `303A:1001` port); flash/provision/read calls are swapped for recorders.

  - Pilot coroutines run via `asyncio.run` (no async plugin). `test_state.py` works only under `tmp_path`.
