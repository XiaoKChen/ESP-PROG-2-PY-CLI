**scripts/** — Platform wrappers that build the one-file executable from source, install a released binary onto PATH, or run the app from source on Termux/Android.

- **Responsibility:** Local PyInstaller builds (`build.ps1` / `build.sh`), release binary installs onto the user's PATH (`install.ps1` / `install.sh`), and a Termux/Android run-from-source launcher (`run-termux.sh`). No Python module imports these scripts.
- **Key files:** `build.ps1`, `build.sh`, `install.ps1`, `install.sh`, `run-termux.sh`
- **Relationships:** `build.*` run `uv sync` and `uv run pyinstaller esp-prog2-flasher.spec --noconfirm` (the spec bundles `hex/`, `packs/`, `firmware/`). CI (`.github/workflows/build.yml`) does not call these scripts; it runs its own PyInstaller builds and publishes `esp-prog2-flasher-windows.exe` / `-macos` / `-linux` on `v*` tags, the exact asset names `install.*` download. `run-termux.sh` reads `[project].dependencies` from `pyproject.toml`.

- **`build.ps1`** — Windows build wrapper: `$ErrorActionPreference = "Stop"`, moves to the repo root, runs `uv sync` and PyInstaller against the spec, reports `dist/esp-prog2-flasher.exe`. The local counterpart of the CI Windows build.
- **`build.sh`** — Linux/macOS build wrapper: the same steps under `set -euo pipefail`, reporting `dist/esp-prog2-flasher`.
- **`install.ps1`** — Windows installer, `install.ps1 [-Version vX.Y.Z]` (default `latest`). Downloads `esp-prog2-flasher-windows.exe` into `%LOCALAPPDATA%\Programs\esp-prog2-flasher\` via `gh release download` when `gh` exists, else `Invoke-WebRequest`. Prompts before replacing an existing PATH install (interactive sessions only; otherwise keeps it) and appends the install directory to the user PATH when missing.
- **`install.sh`** — macOS/Linux installer, `install.sh [vX.Y.Z]` (default `latest`). Picks `esp-prog2-flasher-macos` or `-linux` by `uname -s`, downloads via `gh` or `curl` into `~/.local/bin/esp-prog2-flasher` and marks it executable. Prompts on a TTY before replacing an existing install and prints the PATH export line when `~/.local/bin` is not on PATH.
- **`run-termux.sh`** — Termux/Android launcher, `scripts/run-termux.sh [args...]`. Installs the runtime dependencies into the system pip only when `pyocd`, `esptool`, `serial`, `textual` and `truststore` fail to import (dependency list read from `pyproject.toml` with `tomllib`), then `exec`s `python -m esp_prog2_flasher` with `src/` on `PYTHONPATH`. PyInstaller cannot target Android and uv cannot run on Termux, hence run-from-source. The five import names are hard-coded, so a new runtime dependency needs adding there too.
