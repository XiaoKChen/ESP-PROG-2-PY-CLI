**scripts/** — Local PyInstaller build wrappers, release-binary installers, and a Termux run-from-source launcher for esp-prog2-flasher.

- **Responsibility:** Packaging and distribution helpers: build the one-file PyInstaller executable locally, install a released binary onto PATH, and run the package from source on Termux/Android. No flashing logic, no importable API.
- **Key files:** `build.ps1`, `build.sh`, `install.ps1`, `install.sh`, `run-termux.sh`
- **Relationships:** `build.*` drive `esp-prog2-flasher.spec`. `run-termux.sh` reads `pyproject.toml` and runs `src/` directly. `install.*` download the release assets that the `release` job in `.github/workflows/build.yml` publishes (`esp-prog2-flasher-windows.exe`, `-macos`, `-linux`); the names match.

- **`build.ps1`** — Windows build: moves to the repo root, `uv sync`, then `uv run pyinstaller esp-prog2-flasher.spec --noconfirm`, producing `dist/esp-prog2-flasher.exe`. Stops on the first error (`$ErrorActionPreference = "Stop"`). The local counterpart of the CI build step.
- **`build.sh`** — Linux/macOS build: the same steps under `set -euo pipefail`, producing `dist/esp-prog2-flasher`.
- **`install.ps1`** — Windows installer, optional `-Version vX.Y.Z` (default: latest release). Downloads `esp-prog2-flasher-windows.exe` from `XiaoKChen/ESP-PROG-2-PY-CLI` via `gh release download`, else `Invoke-WebRequest` (public repo only), into `%LOCALAPPDATA%\Programs\esp-prog2-flasher\esp-prog2-flasher.exe`, and appends that folder to the user PATH if missing. If `esp-prog2-flasher` is already on PATH it asks "Replace it? [y/N]"; declining or a non-interactive session exits 0 without installing.
- **`install.sh`** — macOS/Linux installer, optional `vX.Y.Z`. Picks `esp-prog2-flasher-macos` or `-linux` by `uname -s` (any other OS exits 1), downloads with `gh`, else `curl`, into `~/.local/bin/esp-prog2-flasher` and marks it executable; prints an `export PATH` hint when `~/.local/bin` is not on PATH. Prompts before replacing an existing install and keeps it in a non-interactive shell (`-t 0`).
- **`run-termux.sh`** — Runs the tool from source on Termux/Android (PyInstaller cannot target Android; uv does not run on Termux). Needs `pkg install python libusb`; USB access also needs Termux:API.
  1. `cd`s to the repo root; exits 1 if `pip` is missing.
  2. Reads `[project].dependencies` from `pyproject.toml` with `tomllib` into `DEPS`; exits 1 if the list is empty.
  3. Checks each dependency with `importlib.metadata.version()` on the requirement's leading `[A-Za-z0-9._-]+` name, so no import-name map is needed.
  4. If any lookup fails it prints "Installing runtime dependencies (first run)…" and runs `pip install "${DEPS[@]}"`; otherwise it skips the install (fast and offline on repeat runs).
  5. `exec env PYTHONPATH="src…" python -m esp_prog2_flasher "$@"` — the project itself is never installed.
