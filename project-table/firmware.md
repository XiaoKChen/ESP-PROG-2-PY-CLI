- **Responsibility:** Provide the image flashed onto the ESP-Prog-2 by the `flash_probe` path, plus the rationale and rebuild recipe.

- **`esp-prog2.bin`** — A custom build of esp-usb-bridge for the ESP32-S3: **SWD/CMSIS-DAP** interface (not the stock JTAG) and **mass storage disabled**. The CMSIS-DAP USB interface subclass is forced to `0` so pyOCD accepts it. Merged image (bootloader + partition table + app), flashed at offset `0x0`.
- **`README.md`** — Explains why the stock launchpad image (JTAG + MSC) is unsuitable, the ROM-download-mode flashing steps, the exact source edits (SWD overlay, `CFG_TUD_MSC=0`, dropped MSC interface, subclass=0), and the Docker-based `idf.py … merge-bin` rebuild recipe. Also documents the separate `esp-prog2-official-jtag.bin` reference download.
