- **esp-prog2.bin** — 332,992-byte merged firmware image (bootloader + partition table + app) for the ESP-Prog-2's ESP32-S3, flashed at `0x0`. Custom build of Espressif's `esp-usb-bridge` firmware with two changes from stock: SWD/CMSIS-DAP debug interface (`CONFIG_DEBUG_PROBE_IFACE_SWD=y`) instead of default JTAG (`esp_usb_jtag`), required for pyOCD and RA4M1/SWD flashing in this repo; and USB Mass Storage (MSC) removed (`CFG_TUD_MSC=0`, MSC interface dropped from the USB descriptor) so no `ESPPROG_MSC` drive/AutoPlay appears. Built via Docker (`espressif/idf:release-v5.3`, `idf.py set-target esp32s3 build merge-bin`) from a clean clone of `esp-usb-bridge` with source edits to `tusb_config.h`, `usb_defs.h`, `main.c`, and `main/CMakeLists.txt` to strip MSC support.
- **README.md** — Documents the firmware's origin and custom SWD/no-MSC modifications versus Espressif's stock image; explains the flashing procedure (TUI key `p` or `uv run esp-prog2-flasher --flash-probe`, requiring the board be placed in ROM download mode via BOOT+RESET first); gives the exact Docker rebuild command and the list of source-level edits used to remove MSC; and describes the separate official JTAG+MSC image (`esp-prog2-official-jtag.bin`, fetched via `--update-probe-fw`) which is kept apart so it never overwrites the SWD build.
