The `esp_prog2_flasher` Python package — TUI, CLI, and the flashing engine.

### src/esp_prog2_flasher/
- **Responsibility:** Detect the ESP-Prog-2 and a connected RA4M1, flash the target bootloader (pyOCD/SWD), and reflash the ESP-Prog-2's own firmware (esptool), via either a Textual TUI or a headless CLI.
- **Key files:** `flasher.py` (engine), `app.py` (TUI), `cli.py` (entry point).
- **Relationships:** `cli.py` and `app.py` both depend on `flasher.py`; `flasher.py` depends only on pyOCD, esptool (subprocess), pyserial, and truststore — never on UI code.

- **`__init__.py`** — Package marker; exposes `__version__`.
- **`__main__.py`** — Enables `python -m esp_prog2_flasher`; delegates to `cli.main()`.
- **`cli.py`** — argparse entry point and the `esp-prog2-flasher` console script. With no args launches the TUI; flags drive `flasher` headlessly: `--list` (probes + serial ports), `--detect` (probe/target status, exit code 2 if no probe), `--flash` (RA4M1 bootloader), `--flash-probe` (ESP-Prog-2 firmware), `--update-probe-fw` (fetch official JTAG image for reference), with `--hex`/`--probe-bin`/`--port`/`--freq` overrides.
- **`app.py`** — The Textual `FlasherApp`. Auto-detects on mount, shows probe/target/serial/firmware status, and runs flashing in `@work(thread=True)` workers that stream progress and log lines back to the UI. Buttons/keys: detect (`d`), flash target (`f`), flash ESP-Prog-2 (`p`), fetch official firmware (`u`), quit (`q`). "Flash target" is disabled until an RA4M1 is detected.
- **`flasher.py`** — UI-agnostic core. Probe detection (`list_probes`/`find_esp_prog` via pyOCD, matched on Espressif vendor/CMSIS-DAP); target detection (`detect` opens an SWD session against `r7fa4m1ab`, classifies no-probe / no-target / connected / connected-blank); target flash (`flash` via pyOCD `FileProgrammer`); ESP-Prog-2 firmware flash (`flash_probe` shells out to `esptool write-flash 0x0`, parsing `%` for progress); serial-port detection (`find_probe_serial` via pyserial, flags ROM download mode); and `download_probe_firmware` (official JTAG image via urllib + truststore, saved under a separate name). Bundled-asset resolvers (`find_default_hex`, `find_probe_firmware`) walk up from the package/CWD.
