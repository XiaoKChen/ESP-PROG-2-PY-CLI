## esp_prog2_flasher/

- **Responsibility:** The only package in the repo. Provides three layers: a UI-agnostic flashing engine (`flasher.py`) wrapping pyOCD (target) and esptool (probe firmware); a Textual TUI (`app.py`) that drives the engine from background threads; and an argparse CLI (`cli.py`) that either launches the TUI or runs headless flash/detect operations.
- **Key files:** `flasher.py`, `cli.py`, `app.py`, `__main__.py`, `__init__.py`
- **Relationships:** imports from: `pyocd.core.helpers.ConnectHelper`, `pyocd.core.session.Session`, `pyocd.flash.file_programmer.FileProgrammer` (target flashing), `esptool` (probe firmware flashing, invoked via subprocess or in-process shim), `serial.tools.list_ports` (port detection), `truststore` (TLS trust-store injection for firmware download), `textual` (TUI widgets/App) — exposes: `main()` (console-script entry point), `FlasherApp`/`run()`, and the `flasher` module's public functions/dataclasses (`detect`, `flash`, `flash_probe`, `list_probes`, `find_esp_prog`, `find_default_hex`, `find_probe_firmware`, `find_probe_serial`, `download_probe_firmware`, `ProbeInfo`, `DetectResult`, `TargetState`, `ProbeSerial`, `FlasherError`/`ProbeNotFoundError`/`FlashFailedError`).

- **`__init__.py`** — package marker; defines `__version__ = "0.1.0"` and the module docstring describing the package's purpose. No other logic (no side effects at import time).

- **`__main__.py`** — enables `python -m esp_prog2_flasher`; imports and calls `cli.main()` under `if __name__ == "__main__":`.

- **`cli.py`** — argparse-based CLI entry point (`main()`). Builds the parser (`_build_parser`) with flags `--list`, `--detect`, `--flash`, `--flash-probe`, `--update-probe-fw`, `--hex`, `--probe-bin`, `--port`, `--freq`. With no flags, imports `app.run` and launches the Textual TUI. Also intercepts a hidden `flasher.ESPTOOL_SHIM_FLAG` argv[1] to call `esptool.main()` in-process — the dispatch path used when running as a frozen (PyInstaller) build re-executing itself in place of a nonexistent `esptool` script.

- **`app.py`** — Textual TUI, class `FlasherApp(App)` with `TITLE`/`SUB_TITLE`, custom `CSS`, key `BINDINGS` (detect/flash_target/flash_probe/update_fw/quit). Composes status widgets (`probe_status`, `target_status`, `serial_status`, `fw_status`), a hex-path `Input`, buttons, a `ProgressBar`, and a `RichLog`. Action methods (`action_detect`, `action_flash_target`, `action_flash_probe`, `action_update_fw`) dispatch to `@work(thread=True)` worker methods (`detect_worker`, `flash_target_worker`, `flash_probe_worker`, `download_fw_worker`) that call into `flasher` and marshal results back to the main thread via `call_from_thread`. Exposes module-level `run(hex_path, frequency)` which instantiates and runs `FlasherApp`. Never touches USB/serial/subprocess directly — all hardware I/O goes through `flasher`.

- **`flasher.py`** — the UI-agnostic core engine, split into two halves:
  - *Target (RA4M1 over SWD via pyOCD):* constants `ESP_PROG_VID`/`ESP_PROG_PID` (0x303A/0x1002), `TARGET_TYPE` (`"r7fa4m1ab"`), `DEFAULT_FREQUENCY_HZ`; dataclasses `ProbeInfo`, `DetectResult`; enum `TargetState` (`NO_PROBE`, `NO_TARGET`, `CONNECTED`, `CONNECTED_BLANK`); functions `list_probes`, `find_esp_prog`, `detect` (opens a pyOCD `Session`, halts the core, reads PC to distinguish blank vs. programmed flash), `flash` (programs a `.hex` via pyOCD's `FileProgrammer` and resets), `find_default_hex` (locates the bundled `hex/dfu_minima.hex` via `_find_bundled`, which checks a PyInstaller `_MEIPASS` bundle first, then walks up from the package/CWD).
  - *Probe's own firmware (ESP32-S3 via esptool):* constants `PROBE_FIRMWARE_URL`, `PROBE_CHIP` (`"esp32s3"`), `PROBE_FLASH_OFFSET`; dataclass `ProbeSerial` (with `in_download_mode` property); functions `find_probe_firmware`, `find_probe_serial` (via `pyserial`'s `list_ports`), `download_probe_firmware` (fetches Espressif's official JTAG image over HTTPS using `truststore` for OS-trust-store TLS, saved under a distinct filename so it never overwrites the bundled SWD build), `flash_probe` (spawns `esptool` as a subprocess — or re-execs the frozen binary with `ESPTOOL_SHIM_FLAG` when packaged — parsing `(\d+%)` progress from stdout).
  - Exception hierarchy: `FlasherError` (base) → `ProbeNotFoundError`, `FlashFailedError`.
  - Has no dependency on `textual`; imports `pyocd`/`pyserial`/`esptool`/`truststore` lazily inside functions so module import never triggers USB enumeration or network I/O.
