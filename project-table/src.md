### src/esp_prog2_flasher/
- **Responsibility:** All application logic: probe/target detection, RA4M1 bootloader + application flashing, PSoC 6 (IDU Radar) flashing, DFU config-block writing, ESP-Prog-2 firmware reflashing, and the two front ends (argparse CLI, Textual TUI).
- **Key files:** `flasher.py`, `cli.py`, `app.py`, `dfu_config.py`
- **Relationships:** `cli.py` and `app.py` import `flasher.py` and `dfu_config.py`; `flasher.py` imports `dfu_config.py` lazily; `cli.py` imports `app.run` only when no action flag is given. Third-party: pyocd (`ConnectHelper`, `Session`, `FileProgrammer`, `FlashLoader`), intelhex (transitive via pyocd), pyserial, esptool (subprocess / frozen shim), optional truststore, textual. Bundled data (`hex/`, `packs/`, `firmware/`) resolves via `_find_bundled` — PyInstaller `_MEIPASS` first, then walking up from the package/CWD. Exposes the console script `esp-prog2-flasher` (`cli:main`, also `python -m esp_prog2_flasher`).

- **`__init__.py`** — Package docstring and `__version__ = "2.2.0"`.
- **`__main__.py`** — Enables `python -m esp_prog2_flasher` by calling `cli.main()`.
- **`dfu_config.py`** — Pure encoder for the frozen 80-byte v2 DFU config block the bootloader reads byte-for-byte (little-endian: magic `0xDF0C0FDF`, version 2, manufacturer/product strings ≤32 printable ASCII padded `0xFF`, boot CAN ID pair, trailing zlib CRC32). `CONFIG_ADDRESS = 0x40101C00` (RA4M1 data flash); `DATA_FLASH_ENABLE_ADDR = 0x407EC090` (DFLCTL, set before read-back). `build_config_block()`, `boot_ids_for_device()`, `DEVICE_CAN_IDS` (9 ODU/IDU boards — single source of truth) and derived `DEVICE_NAMES`. CAN ID pair is all-or-nothing and 11-bit, `0xFFFF` = unset (bootloader defaults `0x79E`/`0x79F`). Errors: `DfuConfigError`, `InvalidNameError`, `InvalidCanIdError`.
- **`flasher.py`** — UI-agnostic backend; errors derive from `FlasherError` (`ProbeNotFoundError`, `FlashFailedError`); progress/log via callbacks.
  - **Probe discovery:** `list_probes`/`find_esp_prog`/`_choose_raw` prefer an Espressif/ESP-Prog CMSIS-DAP probe (VID `0x303A`/PID `0x1002`), else the first CMSIS-DAP probe.
  - **Detection:** `detect` (RA4M1, `r7fa4m1ab`, bundled slim RA_DFP pack) and `detect_psoc6` (`cy8c6xx5`, built into pyOCD, no pack) share `_detect_target`, which halts and reads PC → `DetectResult`/`TargetState` (`NO_PROBE`, `NO_TARGET`, `CONNECTED`, `CONNECTED_BLANK` at PC `0xFFFFFFFE`). `_open_session(target_type, use_pack)` picks the target per call.
  - **RA4M1:** `flash(hex)` reset-halts, programs via `FileProgrammer`, optionally writes + read-back-verifies the DFU config block; `flash_app(bin)` programs at `APP_BASE_ADDRESS = 0x4000` with `chip_erase="sector"` so the bootloader survives; `write_dfu_config` writes only the block.
  - **PSoC 6:** `flash_psoc6(hex)` loads IntelHex, filters with `psoc6_flash_segments` (drops Cypress metadata `0x90000000–0xA0000000`, refuses anything outside main flash `0x10000000–0x10080000` so SFLASH/eFuse are never written — fails before touching hardware), programs via `FlashLoader`, resets.
  - **ESP-Prog-2 firmware (ESP32-S3):** `find_probe_serial` (download mode inferred from PID ≠ `0x1002`); `flash_probe` runs esptool at `0x0`, parsing percent output, re-exec'ing itself with `--esptool-shim` in frozen builds; `download_probe_firmware` saves Espressif's official JTAG image as `esp-prog2-official-jtag.bin` (checks `0xE9` magic), never overwriting the bundled SWD build.
  - **Bundled-file lookup:** `find_default_hex`, `find_default_psoc6_hex`, `find_default_pack`, `find_probe_firmware`.
- **`cli.py`** — argparse `main()` (`prog="esp-prog2-flasher"`); no options → TUI. Flags: `--list`, `--detect` (+ `--psoc6`), `--flash`, `--flash-psoc6`, `--flash-app BIN` + `--app-address`, `--flash-probe`, `--update-probe-fw`, `--hex`, `--probe-bin`, `--port`, `--manufacturer`, `--product`, `--boot-cmd-id`, `--boot-reply-id`, `--freq`. `--detect` exits 2 only with no probe; `--flash-psoc6` defaults to the bundled PSoC 6 hex; known `--product` devices have fixed CAN IDs (explicit IDs rejected), others are custom; `_resolve_dfu_config`/`_prompt_dfu_config`/`_prompt_boot_ids` handle interactive config. Intercepts `argv[1] == --esptool-shim` to run `esptool.main()` in-process for frozen builds.
- **`app.py`** — Textual `FlasherApp` ("ESP-Prog-2 Flasher") + `run()`. Left "Target (RA4M1)" panel (probe/target status, bootloader `.hex` + Browse, USB manufacturer, device `Select` of `DEVICE_NAMES` + "Custom…", custom name, boot CAN ID inputs, Detect / Flash target). Right column: ESP-Prog-2 firmware panel ("Get official (JTAG)", "Flash ESP-Prog-2"), Application panel (`.bin`, "Embassy bootloader" checkbox switching the base to `0x8000`, Flash app), PSoC 6 (IDU Radar) panel (`.hex` defaulting to the bundled image, Browse, Flash PSoC 6). Progress bar + `RichLog`. Keys: `d` detect, `f` flash target, `a` flash app, `6` flash PSoC 6, `p` flash probe, `u` update fw, `q` quit. Flash target/app require a prior Detect; Flash PSoC 6 only checks the hex exists. Work runs in thread workers (`detect_worker`, `flash_target_worker`, `flash_app_worker`, `flash_psoc6_worker`, `flash_probe_worker`, `download_fw_worker`); `FilePickerScreen` is a suffix-filtered modal browser; `_parse_can_id` validates CAN IDs before the backend.
