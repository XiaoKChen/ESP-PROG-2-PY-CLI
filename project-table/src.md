### esp_prog2_flasher/
- **Responsibility:** Single Python package implementing ESP-Prog-2 probe detection, RA4M1 target bootloader flashing (via pyOCD), DFU USB-name config-block encoding/writing (data flash 0x40101C00), ESP-Prog-2's own firmware reflashing (via esptool), and both a headless CLI and interactive Textual TUI front end.
- **Key files:** `flasher.py`, `dfu_config.py`, `cli.py`, `app.py`, `__main__.py`, `__init__.py`
- **Relationships:** imports `pyocd` (ConnectHelper/Session/FileProgrammer/FlashLoader), `esptool` (subprocess or in-process shim), `textual`, `serial.tools.list_ports`, `urllib`/`truststore` — exposes `cli.main` (console entry point), `app.run` (TUI entry point), and the `flasher.*` / `dfu_config.*` logic API consumed by both.

- **flasher.py** — Core hardware-facing module wrapping the pyOCD API. Auto-detects an ESP-Prog-2 (CMSIS-DAP, VID `0x303A`/PID `0x1002`) and RA4M1 target (`r7fa4m1ab`). `detect()` (probe/target presence + blank-flash PC check), `flash()` (reset-and-halt, program `.hex` via `FileProgrammer`, optionally write the DFU config block, final reset), `write_dfu_config()` (standalone config write), `_program_config_block()` (writes + verifies the 76-byte block at `CONFIG_ADDRESS` via `FlashLoader`, toggling the RA4M1 `DFLCTL` data-flash read-enable before read-back). Also owns the probe's own ESP32-S3 firmware lifecycle: `find_probe_firmware/serial`, `download_probe_firmware`, `flash_probe` (esptool subprocess / frozen-build shim). Exceptions `FlasherError`→`ProbeNotFoundError`/`FlashFailedError`; dataclasses/enums `ProbeInfo`, `TargetState`, `DetectResult`, `ProbeSerial`. Backends imported lazily so module import never triggers USB/network I/O.
- **dfu_config.py** — Encodes the frozen 76-byte DFU manufacturer/product config block (magic `0xDF0C0FDF`, version, length-prefixed ASCII names padded `0xFF`, trailing CRC32) written to data flash `CONFIG_ADDRESS = 0x40101C00`. `build_config_block(manufacturer, product) -> bytes`, validates names (printable ASCII, ≤32) via `_validate_name`, raises `InvalidNameError`/`DfuConfigError`. Defines `DATA_FLASH_ENABLE_ADDR` (the `DFLCTL` register used by the read-back path). Contract mirrors the bootloader's `src/boot/dfu_config.*`.
- **cli.py** — argparse CLI (`main()`). Flags: `--list`, `--detect`, `--flash`, `--flash-probe`, `--update-probe-fw`, `--hex`, `--probe-bin`, `--port`, `--manufacturer`, `--product`, `--freq`. `_resolve_dfu_names` prompts interactively when neither name flag is given and stdin is a TTY. Intercepts `ESPTOOL_SHIM_FLAG` to run `esptool.main()` in-process for frozen builds. No flags → launches the TUI.
- **app.py** — Textual TUI (`FlasherApp`, `HexPickerScreen`, `_HexDirectoryTree`): target panel (detect/flash, `.hex` picker, manufacturer/product inputs) and probe panel (firmware download/flash). Threaded `@work` workers call `flasher.py` without blocking the UI; a `RichLog` streams status. `run(hex_path, frequency)` is the TUI entry point.
- **__main__.py** — Enables `python -m esp_prog2_flasher`; forwards to `cli.main`.
- **__init__.py** — Package docstring and `__version__`.
